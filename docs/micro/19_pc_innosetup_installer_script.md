# Doc 19: InnoSetup Installer Script

## 1. Objective & Scope
Authors `pc_agent/installer/setup.iss` — the InnoSetup script that packages the Wave 3.A PyInstaller bundle (`dist/SlateSyncAgent/`) into `SlateSync_Setup.exe`, registers the `.slatesync` file association, adds/removes the Windows Firewall rule for port `50606`, and creates Start Menu/Desktop shortcuts. The script is described **section-by-section with key directives** (not a giant code dump). Authoring happens in **Wave 3.A**; `ISCC.exe` compilation is **deferred to Wave 3.B** because it needs the `dist/SlateSyncAgent/` bundle (template §6). No Python API → no pytest file (none listed for Doc 19 in template §6).

**Installer behavior contract:** per-machine install to `{autopf}\SlateSync` (elevated — required for the firewall rule, HKCR association and Program Files); Start Menu + Desktop shortcuts; double-clicking a `.slatesync` file launches `SlateSyncAgent.exe` with the document path; install adds, uninstall removes, the `SlateSync WS` allow-rule for TCP `50606`.

**In scope:** authoring `setup.iss` only. **Out of scope:** running `ISCC.exe` (deferred to Wave 3.B), producing `dist/SlateSyncAgent/` (Doc 18), and every Python/Dart source file.

## 5. Implementation Plan
1. **Header & constants.** UTF-8 BOM comment, `#define MyAppName "SlateSync"`, `#define MyAppVersion "1.0.0"`, `#define MyAppExeName "SlateSyncAgent.exe"`, `#define WsPort "50606"`, `#define FirewallRule "SlateSync WS"` — single source for directives below.
2. **`[Setup]` section.** The key fields frozen in §4: fixed `AppId` GUID, `AppName/Version`, `DefaultDirName={autopf}\SlateSync`, `OutputBaseFilename=SlateSync_Setup`, `OutputDir=Output`, `PrivilegesRequired=admin` (needed for the firewall rule), `Compression=lzma2` + `SolidCompression=yes`, optional `SetupIconFile`, plus `DefaultGroupName=SlateSync` and `UninstallDisplayName=SlateSync`. Companion `[Languages]`: `Name: "english"; MessagesFile: "compiler:Default.isl"` (no `[Tasks]` — shortcuts are unconditional per §4).
3. **`[Files]` section.** One recursive entry, verbatim key fields:
```ini
Source: "..\..\dist\SlateSyncAgent\*"; DestDir: "{app}"; Flags: recursesubdirs ignoreversion
```
   paths resolve relative to `pc_agent/installer/`, matching Doc 18's onedir layout (entry point lands at `{app}\SlateSyncAgent.exe`).
4. **`[Icons]` section.** Both shortcuts point at the frozen exe name (`IconIndex 0` — the exe's embedded icon, no separate `.ico` needed):
```ini
Name: "{group}\SlateSync";      Filename: "{app}\SlateSyncAgent.exe"
Name: "{autodesktop}\SlateSync"; Filename: "{app}\SlateSyncAgent.exe"
```
5. **`[Registry]` — `.slatesync` association (HKCR).** Four string values; `Flags: uninsdeletekey` on the type key so uninstall cleans up:
```ini
Root: HKCR; Subkey: ".slatesync";                          ValueType: string; ValueData: "SlateSyncCanvas"
Root: HKCR; Subkey: "SlateSyncCanvas";                     ValueType: string; ValueData: "SlateSync Canvas"
Root: HKCR; Subkey: "SlateSyncCanvas\DefaultIcon";         ValueType: string; ValueData: "{app}\SlateSyncAgent.exe,0"
Root: HKCR; Subkey: "SlateSyncCanvas\shell\open\command";  ValueType: string; ValueData: """{app}\SlateSyncAgent.exe"" ""%1"""
```
6. **`[Run]` — firewall + optional launch.** Rule name and port literals match §3 constants (elevated via `PrivilegesRequired=admin`):
```ini
Filename: "{cmd}"; Parameters: '/C netsh advfirewall firewall add rule name="SlateSync WS" dir=in action=allow protocol=TCP localport=50606'; Flags: runhidden waituntilterminated
Filename: "{app}\SlateSyncAgent.exe"; Description: "Launch SlateSync"; Flags: nowait postinstall skipifsilent
```
7. **`[UninstallRun]` — matching removal.** Symmetric literal with §5 step 6 (identical rule name):
```ini
Filename: "{cmd}"; Parameters: '/C netsh advfirewall firewall delete rule name="SlateSync WS"'; Flags: runhidden waituntilterminated; RunOnceId: "RemoveFirewallRule"
```
8. **Validation pass (authoring-time checklist).** Confirm:
   - `Source: "..\..\dist\SlateSyncAgent\*"` resolves to an existing directory when compiled (Wave 3.B precondition)
   - firewall rule name literal identical in `[Run]` and `[UninstallRun]`; port literal equals `50606` (§3)
   - AppId GUID unchanged across releases (upgrade-in-place, no duplicate installs)
   - no `#include` or path reference escapes this doc's ownership (`docs/`, other sources untouched)

## 6. Testing & Acceptance Criteria
No pytest file (Doc 19 owns none per template §6). Acceptance executes in **Wave 3.B** (Subagent 1, after the Wave 3.A barrier):
1. **Compiles** — `ISCC.exe pc_agent/installer/setup.iss` exits 0 and emits `pc_agent/installer/Output/SlateSync_Setup.exe`.
2. **Firewall rule present** — elevated check after install: `netsh advfirewall show rule name="SlateSync WS"` reports the allow rule for TCP `localport=50606`; running the uninstaller removes it (rule absent afterwards).
3. **`.slatesync` icon registered** — `HKCR\.slatesync` → `SlateSyncCanvas`, `DefaultIcon` = `"{app}\SlateSyncAgent.exe,0"` shows the app icon in Explorer; label reads "SlateSync Canvas".
4. **Shortcuts & payload** — Start Menu/Desktop shortcuts launch `{app}\SlateSyncAgent.exe`; `dist/SlateSyncAgent/**` files land under `{app}` recursively.
5. **Uninstall symmetry** — after running the generated uninstaller: the `SlateSync WS` rule is gone (re-run the `netsh show rule` check), `{app}` is emptied, and the `.slatesync`/`SlateSyncCanvas` keys are removed (`uninsdeletekey`).
Authoring-time sanity (Wave 3.A): script text exists at `pc_agent/installer/setup.iss` and references `..\..\dist\SlateSyncAgent\*`; `Get-Content` reveals the fixed AppId GUID and the `50606` port literal (compilation intentionally not run this wave).

**Wave 3.B verification commands:**
```text
ISCC.exe pc_agent\installer\setup.iss                    → "Successful compile", Output\SlateSync_Setup.exe exists
netsh advfirewall show rule name="SlateSync WS"          → rule found, TCP localport 50606 (elevated prompt)
reg query HKCR\.slatesync /ve                            → REG_SZ "SlateSyncCanvas" (icon visible in Explorer)
reg query HKCR\SlateSyncCanvas\DefaultIcon /ve           → REG_SZ "…\SlateSyncAgent.exe,0"
```

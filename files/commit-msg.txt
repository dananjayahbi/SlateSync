Round 12 (part 4): OCR tool UI

The free-drawn selection is the point of the tool, so it is its own module
rather than a rectangle special-case: OcrSelectionPath owns the sampling
(dropping sub-2-unit noise, rejecting non-finite points) and the painter draws
the loop with a soft wash so the enclosed area is obvious.

OcrPanel encodes the policy that is easy to get wrong:

* the whole-canvas scan is DISABLED on an infinite canvas, because there is no
  bounded area to rasterise -- better to grey out a control than to accept the
  tap and fail after the user waits;
* a zero-percent job shows an INDETERMINATE bar, since rasterising a 300 DPI
  crop reports nothing for a while and a bar stuck at 0% reads as a hang;
* a failure says why, and "no text found" is never dressed up as success;
* the result summary names the provider, which is the only way a user can tell
  the GPU did the work instead of a silent CPU fallback.

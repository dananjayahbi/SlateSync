Round 12 release: 1.0.6

Bumps the version and ships both artifacts.

PyInstaller spec gained `collect_all` for rapidocr and onnxruntime. Both are
needed for non-obvious reasons: rapidocr ships its model catalogue as package
DATA (config.yaml / default_models.yaml), so a bare hiddenimport fails at
runtime with a config error rather than a missing module; and onnxruntime's
DirectML provider lives in its own DLLs, so without collecting them the frozen
exe silently falls back to CPU -- the exact failure mode this feature exists to
avoid. The TensorRT submodule is filtered out (rapidocr cannot import it here).

New `--ocr-selftest` flag. It is deliberately separate from `--smoke`:
`--smoke` must stay instant and pass with no GPU and no model, while this loads
the recogniser and reports which provider ACTUALLY bound. Running it after an
install is the only honest answer to "is the GPU being used?", because ONNX
Runtime demotes an unavailable provider without raising.
